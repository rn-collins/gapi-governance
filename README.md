# GAPI Agent Governance Workbench

A local-first workbench for AI system inventory, risk triage, controls, evaluation, incidents, human oversight, and evidence export.

**Live:** https://gapi-governance.vercel.app

## Repository contents

`index.html`, `privacy.html`, `robots.txt`, `sitemap.xml`, `terms.html`, `vercel.json`

## Local development

Static site. No build step — open `index.html`, or serve the directory with any static file server.

## Deployment

Deployed on Vercel from `main`. Every push to `main` triggers a production build.
